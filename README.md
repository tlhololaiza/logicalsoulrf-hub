# logicalsoulrf-hub

Website for artist LogicalsoulRF

## Project Overview

A modern, responsive website for LogicalsoulRF, a South African music artist. Built with React, TypeScript, and Vite, this site showcases the artist's music, videos, performances, and provides a platform for bookings and fan engagement.

## Features

- **Home Page**: Hero section with streaming links (Spotify, Apple Music, YouTube) and the latest release showcase
- **Music Page**: Curated collection of tracks and releases
- **Videos Page**: Gallery of music videos and performance clips
- **Gallery Page**: Visual content collection featuring artwork and behind-the-scenes content
- **Links Page**: Centralized hub with links to all streaming platforms and social media
- **Bookings Page**: Contact form for booking inquiries using Formspree integration
- **About Page**: Artist biography and information
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices
- **Dark Theme**: Modern dark UI with teal accent colors
- **Smooth Animations**: Framer Motion animations for enhanced user experience
- **Custom UI Components**: Built with shadcn/ui and Radix UI
